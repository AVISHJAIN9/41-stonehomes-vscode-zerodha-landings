# Design Decisions: Zerodha Kite & Stonehomes Finance UI

## Stack Rationale
- **Selection**: `HTML5, CSS3 (Modern Flexbox/Grid), Vanilla JavaScript`
- **Reasoning**: Lightweight bundle overhead, standards-compliant layout structures, and instant page response times.

## Key Considerations
- Modular styling layout separation.
- Resilient client-side state handling.
