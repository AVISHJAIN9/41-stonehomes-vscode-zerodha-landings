# Technical Glossary: Triple Landing Showcase

- **CSS Grid**: A two-dimensional CSS layout engine designed for handling rows and columns simultaneously.
- **fr Unit**: A fractional unit representing a fraction of available space in a CSS Grid container.
- **minmax()**: A CSS Grid sizing function defining a size range between a minimum and maximum bound.
- **Named Grid Lines**: User-defined names for grid tracks (`[col-start]`, `[center-end]`) enabling human-readable grid coordinate placement.
- **Subgrid**: A CSS Grid feature allowing nested child grids to adopt their parent's track sizing.
