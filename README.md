Zerodha-style landing scaffold

Files created:
- `index.html` — minimal landing page using the provided screenshots
- `css/style.css` — simple responsive styles
- `js/main.js` — small helper for year and mobile nav toggle

How to preview

Open `index.html` in a browser or run a small local server:

python3 -m http.server 8000

Then visit http://localhost:8000/ in your browser.
